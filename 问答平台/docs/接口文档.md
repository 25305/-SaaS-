# 接口文档

> 智能问答 SaaS 平台 · HTTP 接口契约（模块 A 交付物，D5 起持续维护）
> 变更接口必须同步本文件，否则下游联调会失败。

---

## 1. 通用约定

### 1.1 统一响应体

所有接口（含异常）返回三字段结构：

```json
{ "code": 0, "message": "ok", "data": { } }
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `code` | `int` / `string` | 成功固定为 `0`；失败为错误码字符串（见 §1.3） |
| `message` | `string` | 面向用户的提示，可直接展示 |
| `data` | `object` / `array` / `null` | 业务数据；失败时可能带附加信息（如配额超限的 `used/limit/reset_at`） |

> **与任务书的偏差**：任务书示例写的是 `"code": "OK"`，本项目沿用既有实现的 `code: 0`
> （`app/core/response.py` 的 `ok()`）。既有测试 `tests/test_isolation.py` 断言 `code == 0`，
> 改动会破坏已通过的用例，故保持一致并在错误码表中如实登记。

### 1.2 鉴权方式

两种凭据，优先级：`X-API-Key` > `Authorization: Bearer <JWT>`。

| 方式 | 请求头 | 适用 | 说明 |
|---|---|---|---|
| JWT | `Authorization: Bearer <access_token>` | 前端管理台 | 登录接口签发，含 `sub` / `tenant_id` / `role` / `jti` |
| API Key | `X-API-Key: sk-...` | 服务端程序调用 | 完整值仅创建/轮换时返回一次，列表只回掩码 |

解析出的 `tenant_id` 会被注入隔离层（`session.info["tenant_id"]`），业务查询一律不手写租户条件。

**角色**：`super_admin`（平台管理员，可跨租户）、`admin`（租户管理员）、`readonly`（只读成员）。

### 1.3 错误码表

| 错误码 | HTTP | 默认提示 | 说明 |
|---|---|---|---|
| `UNAUTHORIZED` | 401 | 未提供认证信息 | 缺少凭据 |
| `INVALID_TOKEN` | 401 | 登录已过期或无效 | Token 过期/被登出（jti 在黑名单） |
| `INVALID_CREDENTIALS` | 401 | 用户名或密码错误 | 登录失败 |
| `API_KEY_INVALID` | 401 | 调用密钥无效 | Key 不存在/已吊销/已过期 |
| `API_KEY_REVOKED` | 401 | 调用密钥已失效 | 同上，语义更具体 |
| `FORBIDDEN` | 403 | 无权限执行该操作 | 角色不足（资源存在但无权） |
| `ACCOUNT_DISABLED` | 403 | 账号已被禁用 | 用户被停用 |
| `TENANT_DISABLED` | 403 | 租户已停用 | 租户被停用 |
| `TENANT_ISOLATION_VIOLATION` | 403/500 | 检测到跨租户数据写入 | 隔离层拦截 |
| `NOT_FOUND` | 404 | 资源不存在 | 含跨租户访问（刻意与"不存在"同码，防泄露存在性） |
| `TENANT_EXISTS` / `USERNAME_EXISTS` / `TENANT_CODE_RESERVED` | 409 | 编码/用户名冲突 | 注册与建租户 |
| `VALIDATION_ERROR` | 422 | 请求参数校验失败 | Pydantic 校验失败 |
| `QUOTA_EXCEEDED` | 429 | 本周期用量已超出配额 | `data` 含 `used_tokens/limit_tokens/used_requests/limit_requests/reset_at` |
| `RATE_LIMITED` | 429 | 请求过于频繁，请稍后再试 | 响应头带 `Retry-After`（秒） |
| `MODEL_SERVICE_ERROR` | 502 | 模型服务暂时不可用 | 上游异常 |
| `INTERNAL_ERROR` | 500 | 服务器内部错误 | 兜底 |

**越权语义区分**：角色不足 → **403**；跨租户访问他人资源 → **404**（不泄露存在性）。

### 1.4 其它通用响应头

| 响应头 | 出现位置 | 说明 |
|---|---|---|
| `X-Request-Id` | 所有请求 | 全链路追踪 ID（中间件注入） |
| `Retry-After` | 429 限流 | 建议重试秒数 |
| `X-Cache` | 问答接口 | `HIT` / `MISS`（缓存是否命中） |
| `X-Quota-Warning` | 问答接口 | `overage`（软超额策略放行时的告警） |

## 2. 认证 `/api/auth`

### 2.1 `POST /api/auth/register`（无需鉴权）

用租户编码创建新租户，并把请求者注册为该租户的管理员。

```json
{ "tenant_code": "jwc", "username": "jwc_admin", "password": "Jwc@123456", "email": "a@b.c" }
```

成功：`{"code": 0, "message": "注册成功", "data": null}`
失败：编码保留 `409 TENANT_CODE_RESERVED`；编码或用户名重复 `409`。

### 2.2 `POST /api/auth/login`（无需鉴权）

```json
{ "username": "academic_admin", "password": "Academic@123", "tenant_code": "academic" }
```

`tenant_code` 可不填（用户名全局唯一）；填写时用于消歧。

```json
{ "code": 0, "message": "ok", "data": {
  "access_token": "eyJ...", "token_type": "bearer", "expires_in": 7200 } }
```

失败：`401 INVALID_CREDENTIALS`、`403 ACCOUNT_DISABLED`、`403 TENANT_DISABLED`。

### 2.3 `GET /api/auth/me`（JWT）

```json
{ "code": 0, "data": {
  "id": 2, "username": "academic_admin", "email": null,
  "role": "admin", "is_super_admin": false, "tenant_id": 2, "tenant_code": "academic" } }
```

### 2.4 `POST /api/auth/logout`（JWT）

把当前 Token 的 `jti` 加入黑名单，之后用同一 Token 请求返回 `401 INVALID_TOKEN`。

> **已知限制**：黑名单是**进程内**存储，多 worker 部署不共享；登出仅对同一进程生效。生产须切 Redis。

## 4. 平台管理 `/api/admin`（`super_admin`）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/admin/tenants` | 租户列表（含成员数量、配额与超额策略），跨租户查询用 `bypass_tenant_filter` |
| POST | `/api/admin/tenants` | 创建租户，同时创建其首个管理员 |
| PATCH | `/api/admin/tenants/{tenant_id}/quota` | 设置租户月度配额与超额策略（FR-D1/FR-D6） |
| POST | `/api/admin/tenants/{tenant_id}/disable` | 停用租户（该租户成员请求立即 403 `TENANT_DISABLED`） |
| POST | `/api/admin/tenants/{tenant_id}/enable` | 启用租户 |
| GET | `/api/admin/usage/overview` | 全局用量概览（跨租户合计 + 按租户明细，FR-A2/FR-F2） |

> `platform` 租户为超管自身所在租户，**禁止停用**（后端拒绝、前端按钮禁用）。

**设置配额** `PATCH /api/admin/tenants/{tenant_id}/quota`（`super_admin`）——PATCH 语义，只更新传入字段；
显式传 `null` 表示该维度不限制：

```json
{ "quota_monthly_tokens": 2000000, "quota_monthly_requests": 20000, "overage_policy": "soft_warn" }
```

`overage_policy` ∈ `reject`（超额直接 429）/ `soft_warn`（放行并回 `X-Quota-Warning: overage`）。

**全局用量概览** `GET /api/admin/usage/overview?range=month`（`super_admin`）——`range` 同 §9
（`today/week/month/custom`）。标量指标只读 `usage_summary`（FR-F6）：

```json
{ "code": 0, "data": {
  "range": { "kind": "month", "start": "2026-10-01", "end": "2026-10-18", "days": 18 },
  "summary": { "tenant_count": 3, "total_requests": 42, "success": 40, "errors": 2,
               "error_rate": 0.0476, "prompt_tokens": 1200, "completion_tokens": 2400,
               "total_tokens": 3600, "cache_hits": 6, "cache_hit_rate": 0.1429,
               "avg_latency_ms": 12, "p95_latency_ms": 40 },
  "by_tenant": [ { "tenant_id": 2, "code": "academic", "name": "学术问答", "is_active": true,
                   "requests": 30, "total_tokens": 3000,
                   "quota_monthly_tokens": 1000000, "quota_monthly_requests": 10000,
                   "overage_policy": "reject", "token_usage_ratio": 0.003 } ] } }
```

## 6. API Key `/api/v1/apikeys`（`admin` / `super_admin`）

### 6.1 `POST /api/v1/apikeys`

```json
{ "name": "官网问答机器人",
  "quota_monthly_tokens": 500000, "quota_monthly_requests": 5000,
  "rate_limit_per_minute": 120, "rate_limit_per_hour": 3000 }
```

配额与限流字段**留空表示继承租户**。

```json
{ "code": 0, "data": {
  "id": 7, "name": "官网问答机器人", "key": "sk-...（完整值，仅此一次）",
  "masked": "sk-abc123...xyz9", "warning": "完整 Key 仅显示一次,请立即保存到安全位置;之后只能看到掩码。" } }
```

### 6.2 `GET /api/v1/apikeys`

只返回掩码，**任何接口都不会再返回完整值**。

### 6.3 `POST /api/v1/apikeys/{key_id}/rotate`

签发新 Key，旧 Key 保留 24 小时切换窗口后过期（非立即失效）。

```json
{ "code": 0, "data": { "id": 8, "key": "sk-...（新 Key，仅此一次）", "masked": "sk-...",
  "old_key": { "id": 7, "masked": "sk-abc123...xyz9", "status": "expiring",
               "expire_at": "2026-10-19T12:00:00" } } }
```

### 6.4 `DELETE /api/v1/apikeys/{key_id}`

状态置 `revoked`，该 Key 的调用**立即**返回 `401 API_KEY_INVALID`。

## 7. 配额与用量 `/api/v1`

### 7.1 `GET /api/v1/quota/status`

读取本身会触发惰性周期重置（跨月自动归零）。

```json
{ "code": 0, "data": {
  "used_tokens": 1234, "limit_tokens": 1000000,
  "used_requests": 3, "limit_requests": 10000,
  "reset_at": "2026-11-01", "policy": "reject" } }
```

### 7.2 `GET /api/v1/usage/by-key?days=30`

按 Key 分组的用量（`days` 范围 1~90，不填为全部历史）；`key_id` 为 `null` 表示 JWT 登录态调用。

```json
{ "code": 0, "data": [
  { "key_id": 7, "masked": "sk-abc123...xyz9",
    "requests": 12, "prompt_tokens": 300, "completion_tokens": 600, "total_tokens": 900 } ] }
```

## 8. 问答 `/api/v1/qa/ask`

```json
{ "question": "牛顿第二定律是什么？", "model": null }
```

**链路顺序不可调换**：限流 → 配额预检 → 查缓存 → 调模型。

```json
{ "code": 0, "data": {
  "answer": "...", "sources": ["第一条引用片段", "..."],
  "model": "local-simulation", "model_provider": "local-simulation",
  "cache_hit": false,
  "tokens": { "prompt_tokens": 10, "completion_tokens": 20, "total_tokens": 30 },
  "latency_ms": 4 } }
```

| 场景 | 结果 |
|---|---|
| 配额超限且策略 `reject` | `429 QUOTA_EXCEEDED`，`data` 含 `used/limit/reset_at`；**不调用模型** |
| 配额超限且策略 `soft_warn` | 200 放行，响应头 `X-Quota-Warning: overage` |
| 缓存命中 | 200，响应头 `X-Cache: HIT`，`tokens` 全 0（未调用模型），仍返回 `sources` |
| 缓存未命中 | 200，响应头 `X-Cache: MISS` |
| 限流触发 | `429 RATE_LIMITED`，响应头 `Retry-After: <秒>` |

缓存 key 带租户前缀（`t:{tenant_id}:qa:...`），禁止跨租户命中。

## 9. 用量看板 `/api/v1/dashboard`

`GET /api/v1/dashboard?range=month`（`range` ∈ `today/week/month/custom`；`custom` 时另传 `start`/`end`）。

标量指标与趋势**只读 `usage_summary` 汇总表**（接口耗时恒定，无全表扫描，FR-F6）。

```json
{ "code": 0, "data": {
  "range": { "range": "month", "start": "2026-10-01", "end": "2026-10-18" },
  "summary": { "total_requests": 12, "success": 11, "errors": 1, "error_rate": 0.083,
               "prompt_tokens": 300, "completion_tokens": 600,
               "avg_latency_ms": 6, "p95_latency_ms": 12,
               "cache_hit_rate": 0.17, "quota_rejected": 0,
               "summary_updated_at": "2026-10-18T10:05:00" },
  "trend": [ { "date": "2026-10-18", "requests": 5, "prompt_tokens": 120,
               "completion_tokens": 240 } ],
  "by_key": [ { "key_id": 7, "key_prefix": "sk-abc123", "name": "官网问答机器人",
                "requests": 5, "total_tokens": 900 } ],
  "latency_distribution": [ { "bucket": "0-50ms", "count": 5 } ],
  "generated_at": "2026-10-18T10:06:00" } }
```

> `by_key` 与 `latency_distribution` 依赖明细表才能计算，已限定在**有界时间区间**内聚合
> （所有对 `usage_record` 的查询都带 `created_at >=` / `<` 条件，测试用 SQL 抓取断言固化）。

## 10. 账单 `/api/v1/billing`

`period` 取值：`today` / `week` / `month` / `YYYY-MM` / `YYYY-MM-DD`，解析为左闭右开区间 `[start, end)`。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/summary?period=month` | 账单合计（区间加权平均延迟 + 日 P95 取最大） |
| GET | `/daily?period=month` | 按日明细行（只读 `usage_summary`） |
| GET | `/detail?period=month&limit=5000` | 流水明细（`limit` 1~50000，逆序，带 `request_id`） |
| GET | `/verify?period=month` | 可追溯校验（自动化，替代人工抽查） |
| GET | `/export?period=month&fmt=csv` | 导出账单（`fmt` ∈ `csv`/`xlsx`），带 `Content-Disposition` |

`/verify` 响应：

```json
{ "code": 0, "data": {
  "traceable": true, "period": { "start": "2026-10-01", "end": "2026-10-18" },
  "checked": { "requests": 12, "prompt_tokens": 300, "completion_tokens": 600, "cache_hits": 2 },
  "mismatches": {} } }
```

`traceable=false` 时 `mismatches` 给出 `{ "字段": { "bill": x, "detail": y } }`。
