# 部署说明

## 开发环境

推荐 Python 3.11 或 3.12。进入 `问答平台/backend` 后执行：

```powershell
py -3.11 -m pip install -r requirements.txt
py -3.11 -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

前端在仓库根目录的 `frontend`：

```powershell
npm install
npm run dev
```

## MySQL 8.0

创建 `smartqa_saas` 数据库并复制 `backend/.env.example` 为 `.env`，将
`DATABASE_URL` 改成实际账号。启动服务时会自动创建缺失表并写入演示租户；
生产环境必须更换 `JWT_SECRET`、关闭演示账号，并先完成备份恢复演练。

## 验证

```powershell
py -3.11 -m pytest backend/tests -q
npm run build
```

没有配置真实模型时，`/health` 会以 503 标记模型未配置；这不影响 `/docs`、
租户隔离、配额、限流和账单接口的本地演示。
